# Химия · Конструктор работ

Сайт для создания подборок задач по химии.

Основная страница — конструктор; служебный раздел — `/admin/`. Служебный адрес без пароля, по решению владельца.

Публикация выполняется GitHub Actions: части архива объединяются, проверяются по SHA-256 и разворачиваются на GitHub Pages. Архив содержит HTML, открытый JavaScript, данные и исходные учебные PDF. Локальные базы, резервные копии и материалы рабочего окружения не публикуются.
